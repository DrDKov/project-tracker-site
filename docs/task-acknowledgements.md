# Подтверждение ознакомления с задачей

Слева в верхней строке карточки находится глазик. Справа сохранены звёздочка и чекбокс выполнения.

- Неактивный глазик: назначенные исполнители ещё не подтвердили ознакомление.
- Исполнитель нажимает глазик один раз; подтверждение сохраняется с серверным временем.
- Зелёный глазик: все исполнители подтвердили ознакомление.
- Жёлтый глазик и счётчик: подтвердили не все, например 1/2.
- Повторное нажатие на активный глазик, либо нажатие владельца, открывает имена исполнителей и время подтверждения.
- Отметка не меняет статус и не означает завершение. Для завершения остаётся отдельная галочка.

## Сохранение и доступ

`task_acknowledgements` хранит отдельную неизменяемую запись на исполнителя и назначение. RLS разрешает подтверждать только собственное актуальное назначение активному авторизованному пользователю. Владельцы и участники видят отметки только доступных им задач.

Обычные изменения задачи сохраняют отметки. `sync_task_assignees` обновляет исполнителей разницей, не удаляя существующие назначения. Удаление назначения удаляет его отметку через внешний ключ. Повторное назначение получает новый идентификатор. Для старых задач с `assignee_id` без связующей записи используется серверная `assignee_revision`, обновляемая только при смене исполнителя.

Realtime обновляет только значок/сводку, без перерисовки карточки. После восстановления соединения и возвращения в приложение отметки перечитываются. При отсутствии Realtime есть резервная синхронизация раз в 15 секунд. Ошибка запроса не создаёт ложную отметку; двойное нажатие не отправляет дубли.

## Проверка

- `tests/task-acknowledgements.test.cjs`: собственное/чужое назначение, двойное нажатие, ошибки, несколько исполнителей, старые задачи, повторное назначение, неизменность статуса.
- `supabase/tests/task_acknowledgements.sql`: проверки под authenticated RLS в транзакции с полным rollback; реальные задачи не изменяются, тестовые уведомления не отправляются.
- `tests/compact-preview.cjs`: две роли в отдельных окнах, синхронизация через тестовое событие; данные только в памяти, соединения с рабочей базой нет.

## Текст для анонса

### Новая функция: «Увидел задачу»

Теперь слева вверху карточки есть значок глаза. Если вам назначили задачу, ознакомьтесь с ней и нажмите на глазик — так вы подтвердите, что увидели назначение. Владелец сразу увидит отметку, без перезагрузки страницы и лишних сообщений «задачу получил».

Зелёный глазик означает, что ознакомились все исполнители. Если подтвердили не все, рядом будет счётчик. Нажмите на значок, чтобы узнать, кто уже подтвердил ознакомление и когда.

Важно: глазик — подтверждение ознакомления, а не выполнения. Когда задача готова, отметьте её отдельной галочкой справа.
